# MP3プレーヤー（Android）

バックグラウンド再生とホーム画面ウィジェットに特化した、シンプルな音声プレーヤーです。

## 機能
- 再生・一時停止 / 次の曲 / 曲の最初に戻る / ±10秒
- 再生速度 0.50〜3.00倍（0.05刻み、音程はそのまま）
- 前回の曲・位置・速度を記憶して続きから再生
- ウィジェット：曲名表示、再生・一時停止、-30 / -10 / +10 / +30秒、+1分
- バックグラウンド対策：一時停止中もサービスを維持、画面オフ中のスリープ防止、
  電話中は自動停止→終われば再開、ナビ音声中は音量を下げる、イヤホンが抜けたら停止

## APKの作り方（GitHub Actions）
1. GitHubで新しいリポジトリを作り、このフォルダの中身を全部アップロード
   （`.github` フォルダも忘れずに）
2. 「Actions」タブでビルドが自動で始まる（5分ほど）
3. 「Releases」に `mp3player.apk` が出るので、スマホでダウンロードしてインストール

コードを修正してアップロードし直すと、新しいAPKが自動で作られ、上書きインストールで更新できます。

## 初回の使い方
1. 通知の許可 →「許可」
2. 「電池最適化を解除」→「許可」（バックグラウンドで止められないようにするため）
3. 「フォルダを選ぶ」→ mp3が入っているフォルダを選んで「このフォルダを使用」
4. ホーム画面を長押し →「ウィジェット」→「MP3プレーヤー操作」を配置
